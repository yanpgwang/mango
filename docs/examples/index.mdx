## Before you run

The terminal UI includes an offline demo. The approval, team, and coding examples
require a running Mango deployment and a [configured model](../guides/model-configuration.md).
Their commands connect to that deployment; start it before running the client.

:::info[Coding example support]

The coding example currently uses the explicit `cloud` Environment path for
File inputs and output publication. Those mounts are not yet available through
the default self-hosted Docker worker. See the example's prerequisites before running it.

:::
